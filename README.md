# AgentFlowX

AgentFlowX is an AI-powered business operations platform designed to automate workflows such as client management, invoice handling, audit tracking, and intelligent business assistance.

Built as a full-stack SaaS application using React, Node.js, PostgreSQL, and AI agent workflows.
